# Background asset provenance

All backgrounds were generated for this project with the built-in image_gen tool on 2026-09-17. No CLI fallback, external stock imagery, or API key was used. Original PNG outputs are preserved in `assets/source/`. Runtime copies are encoded as quality-90 WebP in `public/assets/`, reducing total image transfer from 12.99 MB to 1.65 MB without changing image composition or dimensions. Puzzle symbols and clues are rendered deterministically as UI/SVG and are not embedded as unreliable text in the generated backgrounds.

The four square atlases use a 2×2 layout: north, east / south, west. `vertical.png` uses a 4×2 layout: ceilings across the top, floors across the bottom, in room order.
