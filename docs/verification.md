# 検証記録

最終更新: 2026-09-18。Windows / Chrome / Playwright MCP。

## ビルドとテスト

- `mise run build`: TypeScript型検査とViteビルド。
- `mise run test`: 29件（機構・進行15、視点移動9、写真5）。
- 写真の検査は24方向・44対象・14種類の持ち物の表裏・開閉差分を対象とし、未参照画像がないことも確認。

## 写真方式の通しプレイ

新しい接写画面で第一室から全20個の謎を順に解除し、エンディングの表示と `finished: true` を確認した。解除フラグを書き換えて通しプレイを完了したものではない。ダイヤルの連続回転の一部には、最初のポインター操作に続けてDOMクリックを使用した。

時計、引き出し、配電盤、配管、計量槽、環、フィルム、五音の機構、連動輪、最後の錠を写真内で操作。持ち物を部屋で選んで取り付け、正解条件がそろうと自動で解除されることを確認した。

## 戻り先と保存

- 壁の右面→天井→下で同じ右面。
- 壁の右面→床→上で同じ右面。
- 背面→天井で再読み込み→再開→刻印の接写→下で天井→下で背面。
- レンチの接写→取得→下で床→上で正面。
- 持ち物の裏面でキーボードの下を押し、元の部屋画面へ戻る。

## 輪郭と写真

- 390×844で全24視点を巡回。レンチ取得後の43対象は、SVG内部にクリックできる点があることを `isPointInFill` と `elementFromPoint` で確認。
- レンチは取得前の検証用状態でも確認。写真内の実物をクリックし、接写と遠景の取得後写真への切り替えを確認。
- 棚の紙と背後の点検蓋が重なる箇所は、小さい対象を前面に描く順序に修正し、紙の直接クリックを再確認。
- 右端の棚と移動用の三角の干渉を修正し、棚の仕掛けを解除。
- 時計、引き出し、計量槽、透過板、紙の接写を実画面で視覚確認。
- 紙の接写で、開いているダイアログ0、ナビゲーションの三角1を確認。
- 320×740で持ち物の裏面、下の三角1、ダイアログ0、横方向のあふれなしを確認。
- 1280×850でも接写と操作を確認。

通しプレイ後の写真・輪郭の点検には専用のローカル検証用状態を使用した。ユーザーの既存セーブはリセットしていない。

## 素材整理

採用写真100ファイルを `public/images/` に配置。元PNG、候補コンタクトシート、置き換えた写真を現在のツリーから削除。寸法・容量・SHA-256は `docs/photographs.json` に記録。

コンソールエラー・警告なしを確認。

## 未検証の範囲

- iPhone・Android実機、Safariでの操作は未検証。スマホ相当のブラウザ画面幅で確認した。
- 初見プレイヤーの所要時間・難易度・恐怖感は未計測。
- 旧セーブが天井・床にあり元の壁を記録していない場合、その過去の向きは復元できないため正面を戻り先とする。新しいセーブは元の壁を保持する。
