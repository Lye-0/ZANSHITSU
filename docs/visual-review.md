# 写真と重ね描画の目視修正（2026-09-18）

## 起点

`aa50b3a` の写真接写に対するユーザー指摘を受け、ブラウザで再確認した。
以前の「当たり判定内の点がクリックできる」という検査だけでは、写真の物体と輪郭が一致することを確認できていなかった。

## 修正

- 時計図のSVGに幅・高さを明示し、紙の内側に収めた。線の太さと位置を調整。
- 差し込み口とリセット操作を写真ごとの取付位置へ移動。写真から浮いていた共通の円盤装飾を除去。
- 排水口の環の中心を補正し、環・ダイヤル・小蓋の下に元の金属や木目が見えるようにした。
- 刻印に微細なかすれを加え、写真と重ね描画が同じ明るさ設定を受けるようにした。濃度を下げた後、実寸で読めるか再確認して調整。
- 天井の刻印を照明から外し、通常視点側の調査位置も対応する位置へ変更。
- スクリーン下端の手掛かり、四つの窪みの記号、鏡の文字、引き出しの紙をそれぞれの表面へ配置。
- 映写室の紙は、元の写真に紙自体が写っていなかったため、内蔵imagegenによる接写写真へ差し替え。通常視点にも紙を配置。
- 通常視点の引き出し、机上の紙、薬品棚、配管、浴槽、排水口、スクリーン、映写機、電話、連動輪などの輪郭を引き直した。映写機と床のフィルムはSVGパスで外形を表現。
- 引き出し・薬品棚・小箱は、開いた後の写真に合わせた輪郭へ切り替える。
- 持ち物の刻印も個別に位置・角度・濃度を調整。環状部品の文字は穴の中央から金属の縁へ移動。

## 確認方法

ブラウザ操作スキルの `agent-browser` CLIとPlaywright MCPを使用。
検証用の `http://127.0.0.1:53947/` に限って状態を準備し、通常利用の4187番ポートのセーブデータは変更していない。

- 全24方向を実アプリで表示し、輪郭を表示したスクリーンショットを目視確認。
- 全44対象の接写を実アプリで開き、修正前後のスクリーンショットを比較。
- 全44対象について、表示中の輪郭内で他要素に遮られない点を探し、マウスクリックで対応する接写が開くことと、下ボタンで戻ることを確認。
- 持ち物14種類の裏面を実際に開いて、刻印と写真の位置関係を確認。
- 開いた引き出し・薬品棚・小箱も目視で位置を補正し、クリックと接写からの復帰を再確認。
- CLIでは新規プレイから左の壁へ移動し、机上の紙をクリックして接写・復帰を確認。390×844でも紙から図がはみ出さず、戻る操作だけが表示されることを目視確認。
- 通常画面1100×1000、接写800×800、CLIの横長画面と390×844で確認。

状態を準備した目視確認は、最初からの自然な謎解きプレイとは区別する。今回の変更は表示と当たり判定が中心で、謎の答えや進行条件は変更していない。
実機のSafariや全ての画面比率は未検証。

最終ビルド成功。既存テスト29件成功。画像参照・未使用画像の検査も成功。
