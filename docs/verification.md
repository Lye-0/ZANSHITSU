# 検証記録

実施日: 2026-09-17。Windows / Chrome / Playwright MCP。

## ビルドと機構

- `mise run build`: TypeScript の型検査と Vite の公開用ビルド成功。
- `mise run test`: Vitest 15件成功。
- 水量の保存、槽の容量、配管全9セルの接続、連動輪、行をまたがない配電盤操作、スライドの隣接制約を検証。
- スライド初期配置の最短解は幅優先探索で20手。ゲームの三段階目のヒントに同じ合法手順を掲載し、テストで検証。
- 条件を無視した解除の拒否、誤答の拒否、報酬の重複防止、取り付け済み部品の復元、破損した保存データの検出を検証。
- 全20個を依存関係順に解く状態遷移テストで、4銘板の保持と終了状態を確認。

## ブラウザで確認した経路

新規開始 → 第一室 → 第二室 → 映写室 → 帰室 → 過去の部屋の再訪 → 最後の扉 → エンディング。

Playwright MCPから画面上の操作部品を使って全20個を解除し、`finished: true` と解除件数20、銘板4枚を読み取り確認した。解除フラグを書き換える方法では進行させていない。ダイヤルの連続操作とスライドの一部には、最初のポインター操作に続いてDOMのクリックイベントを使用し、状態更新を待った。

確認項目:

- 壁4面・天井・床の移動、扉による部屋移動、既訪問室への移動。
- 誤答とやり直し、部品の取り付け、道具の取得、所持品の裏面。
- 手掛かりの記録、部屋別の記録一覧、記録からの再閲覧。
- 第一室から第二室への移動後に再読み込みし、進行と所持品を復元。
- 音を有効にした五音の機構、環境音の設定。
- 最終室の配電盤から全室の天井へ戻り、連動輪と最終錠まで進行。
- 390×844の画面で全24視点を巡り、すべての操作領域の中心点が移動ボタンなどに遮られていないことを `elementFromPoint` で確認。
- 当初見つかった、棚の紙・床の工具と移動ボタンの重なりを修正し、該当操作と全視点確認を再実施。

## 公開用ビルド

Vite preview の http://127.0.0.1:4187/ で確認。

- 1280×800: タイトル・開始・設定・矢印キーでの移動・三段階ヒントを操作。
- 再読み込み後に明るさ1.2、動きOFF、ヒント段階3を復元。
- 320×740: 本体と開いたヒントダイアログに横方向のあふれがないことを確認。
- 配信用WebP全5ファイルが HTTP 200 / image/webp を返す。
- 確認したセッションでコンソールエラー0件、警告0件。

## 検証の限界

- スマホ相当の画面幅でのブラウザ検証。iPhone・Android実機、Safariは未検証。
- 解法を知った自動操作での確認。初見プレイヤーの所要時間・難易度・恐怖感は未計測。
- 60〜90分は設計目標であり、自動テスト中の経過時間をプレイ時間の根拠にしていない。
- 端末間のセーブ同期はなく、保存は同じオリジン・同じブラウザ内。
