# 写真の由来と採用版

背景・接写・持ち物・状態差分は、組み込みの画像生成ツールで制作した写真です。CLI/APIへの切り替えや外部ストック写真は使用していません。

決定版は `public/images/` にWebP形式で保存しています。数値・記号・針・水位はゲーム側で正確に描画し、写真の表面に位置合わせします。

- [ディレクトリ規約と採用方針](photographs.md)
- [全写真の一覧・寸法・ハッシュ](photographs.json)
- [生成時のプロンプト](image-prompts.md)

画像生成後に対象別の切り出し、必要な拡大、WebPへの形式変換を行っています。リポジトリの現在のツリーには、候補画像・コンタクトシート・重複する元PNGを残しません。
